Chapter 25 - Image Maps in HTML


What are Image Maps?

An image map is an image with clickable areas. These clickable areas, called hotspots, act as links to other web pages, files, or locations within the same page. Image maps allow you to create complex, interactive images where different regions perform different actions when clicked.

Image maps are useful when you want to create a visual navigation system, such as an interactive map, diagram, or any image where different parts should link to different destinations.


Types of Image Maps

There are two types of image maps:

  1. Client-side image maps: The mapping information is contained within the HTML document and processed by the browser. This is the recommended approach.
  2. Server-side image maps: The mapping information is processed by a server-side script. This is an older approach and is generally not recommended for modern web development.

In this chapter, we'll focus on client-side image maps, which are more efficient, accessible, and widely supported.


Creating a Client-Side Image Map

To create a client-side image map, you need three main components:

  1. An <img> element with a usemap attribute that references the map's name
  2. A <map> element with a name attribute that matches the usemap reference
  3. One or more <area> elements within the map element, defining the clickable regions
<img src="image.jpg" alt="Description" usemap="#mapName">

<map name="mapName">
  <area shape="shape" coords="coordinates" href="link.html" alt="Description">
  <area shape="shape" coords="coordinates" href="link2.html" alt="Description">
</map>

The <area> Element

The <area> element defines a clickable area within an image map. It has several important attributes:

Attribute Description
shape Specifies the shape of the area (rect, circle, poly, default)
coords Specifies the coordinates of the area
href Specifies the URL of the link
alt Provides alternative text for the area (important for accessibility)
target Specifies where to open the linked document (_blank, _self, etc.)

Shape Types and Coordinates

The <area> element supports different shapes, each requiring specific coordinate formats:

Shape Coordinates Format Example
rect (rectangle) x1,y1,x2,y2
(top-left and bottom-right corners) 		shape="rect" coords="34,44,270,350"
circle x,y,r
(center point and radius)		 shape="circle" coords="125,125,75"
poly (polygon) x1,y1,x2,y2,...,xn,yn
(series of points) 		shape="poly" coords="140,121,181,116,204,160,204,222,191,270,140,329,85,271,71,216,76,136,113,121"
default No coordinates needed
(covers the entire image) 		shape="default"

The coordinates are measured in pixels from the top-left corner of the image (0,0).


Example: Simple Image Map

Here's a simple example of an image map with rectangular and circular regions:

<img src="workspace.jpg" alt="Workspace with computer, phone, and coffee" usemap="#workspaceMap" width="600" height="400">

<map name="workspaceMap">
  <!-- Computer area (rectangle) -->
  <area shape="rect" coords="50,50,350,200" href="computer.html" alt="Computer">

  <!-- Phone area (circle) -->
  <area shape="circle" coords="450,100,50" href="phone.html" alt="Phone">

  <!-- Coffee cup area (polygon) -->
  <area shape="poly" coords="400,250,450,250,475,300,425,350,375,300" href="coffee.html" alt="Coffee Cup">
</map>

Creating Image Maps

Determining the exact coordinates for complex shapes can be challenging. Fortunately, there are several online tools that can help you create image maps:

  • Image-Map.net - A free online tool for creating image maps
  • Mobilefish.com Image Map Editor - Another free online image map creator
  • Summer HTML Image Map Creator - A simple, open-source image map editor

These tools allow you to upload an image, draw shapes on it, and generate the HTML code for your image map.


Adding Interactivity with JavaScript

You can enhance image maps with JavaScript to create more interactive experiences. For example, you can highlight areas when users hover over them:

<style>
  .map-container {
    position: relative;
    display: inline-block;
  }

  .highlight {
    position: absolute;
    background-color: rgba(255, 255, 0, 0.3);
    pointer-events: none; /* Allows clicks to pass through */
    display: none;
  }
</style>

<div class="map-container">
  <img src="world-map.jpg" alt="World Map" usemap="#worldMap" width="800" height="400">
  <div id="northAmerica" class="highlight" style="left: 67px; top: 48px; width: 217px; height: 164px;"></div>
  <div id="southAmerica" class="highlight" style="left: 187px; top: 211px; width: 91px; height: 157px;"></div>
  <!-- More highlight divs for other regions -->
</div>

<map name="worldMap">
  <area shape="poly" coords="67,102,164,48,..." href="north-america.html" alt="North America" onmouseover="showHighlight('northAmerica')" onmouseout="hideHighlight('northAmerica')">
  <area shape="poly" coords="187,211,232,205,..." href="south-america.html" alt="South America" onmouseover="showHighlight('southAmerica')" onmouseout="hideHighlight('southAmerica')">
  <!-- More areas -->
</map>

<script>
  function showHighlight(id) {
    document.getElementById(id).style.display = 'block';
  }

  function hideHighlight(id) {
    document.getElementById(id).style.display = 'none';
  }
</script>

Accessibility Considerations

To ensure your image maps are accessible to all users, including those using screen readers or other assistive technologies, follow these best practices:

  1. Always include alt attributes for both the <img> element and each <area> element
  2. Provide alternative navigation options in addition to the image map
  3. Use clear, descriptive text for the alt attributes
  4. Consider adding visible labels or a text-based legend near the image map
  5. Test with screen readers to ensure the image map is navigable

Responsive Image Maps

Traditional image maps use fixed pixel coordinates, which can cause issues when the image is resized on different devices. To create responsive image maps, you can use JavaScript libraries like Image Map Resizer or jQuery RWD Image Maps.

<!-- Include the Image Map Resizer script -->
<script src="imageMapResizer.min.js"></script>

<!-- Your image map code -->
<img src="image.jpg" alt="Description" usemap="#myMap" style="max-width: 100%; height: auto;">
<map name="myMap">
  <area shape="rect" coords="50,50,350,200" href="#" alt="Area 1">
  <!-- More areas -->
</map>

<script>
  // Make the image map responsive
  imageMapResize();
</script>

Limitations and Alternatives

While image maps can be useful, they do have some limitations:

  • Maintenance: If the image changes, all coordinates need to be updated
  • Responsiveness: Traditional image maps don't scale well without JavaScript
  • Complexity: Creating complex shapes can be time-consuming
  • Mobile usability: Small clickable areas can be difficult to tap on mobile devices

For modern web development, consider these alternatives to image maps:

  • SVG (Scalable Vector Graphics): SVG elements can be made clickable and scale naturally
  • CSS positioning: Overlay clickable elements on top of an image using absolute positioning
  • Canvas with JavaScript: Create interactive graphics with the HTML5 canvas element
  • Interactive mapping libraries: For geographical maps, consider libraries like Leaflet or Google Maps API

Conclusion

Image maps provide a way to create clickable regions within an image, allowing for visual navigation and interactive elements. While they have some limitations, they can still be useful for certain applications, especially when enhanced with JavaScript for better responsiveness and interactivity.

When creating image maps, remember to focus on accessibility, consider responsive design, and evaluate whether an image map is the best solution for your specific needs.

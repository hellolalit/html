Chapter 36 - Script and Noscript Tags in HTML5


The Script Tag

The script tag is used to embed or reference executable code, typically JavaScript, within an HTML document. It allows you to add interactivity, dynamic content, and behavior to your web pages. The script tag can be placed in the head or body section of an HTML document.


Basic Script Tag Syntax

<script>
  // JavaScript code goes here
  function greet() {
    alert("Hello, World!");
  }
</script>

Script Tag Attributes

The script tag has several important attributes:

  • src - Specifies the URL of an external script file
  • type - Specifies the MIME type of the script (default is "text/javascript")
  • async - Specifies that the script should be executed asynchronously
  • defer - Specifies that the script should be executed after the page has finished parsing
  • crossorigin - Configures CORS settings for the script
  • integrity - Allows browsers to verify that a fetched script has not been manipulated

External JavaScript Files

You can include external JavaScript files using the src attribute:

<script src="script.js"></script>

When using the src attribute, any content between the opening and closing script tags is ignored.


Async and Defer Attributes

The async and defer attributes control how the browser loads and executes scripts:

<!-- Regular script: blocks HTML parsing while downloading and executing -->
<script src="regular.js"></script>

<!-- Async script: downloads in parallel, executes as soon as available -->
<script src="async.js" async></script>

<!-- Defer script: downloads in parallel, executes after HTML parsing -->
<script src="defer.js" defer></script>

Script Placement

Scripts can be placed in the head or body section of an HTML document:

<!-- In the head section -->
<head>
  <script>
    // JavaScript code
  </script>
</head>

<!-- At the end of the body section (recommended) -->
<body>
  <!-- HTML content -->
  <script>
    // JavaScript code
  </script>
</body>

Placing scripts at the end of the body is often recommended to ensure that the HTML content is loaded before the scripts run, which can improve perceived page load times.

The Noscript Tag

The noscript tag defines alternate content to be displayed when scripts are not supported or disabled in the browser. It provides a fallback for users who have JavaScript disabled or browsers that don't support JavaScript.


Basic Noscript Tag Syntax

<noscript>
  Your browser does not support JavaScript or it is disabled.
  Please enable JavaScript to view this website properly.
</noscript>

The noscript content above will only be visible if JavaScript is disabled in your browser.


Using Noscript in the Head Section

The noscript tag can also be used in the head section to provide alternate stylesheets or meta redirects for browsers with JavaScript disabled:

<head>
  <script>
    // JavaScript code
  </script>
  <noscript>
    <link rel="stylesheet" href="noscript.css">
    <meta http-equiv="refresh" content="0;url=noscript.html">
  </noscript>
</head>

Best Practices for Script and Noscript Tags

  • Use external JavaScript files for better caching and maintainability
  • Consider using async or defer attributes for non-critical scripts
  • Place scripts at the end of the body when possible
  • Always provide meaningful fallback content in noscript tags
  • Ensure your website is still usable even without JavaScript
  • Use modern JavaScript features but provide polyfills for older browsers

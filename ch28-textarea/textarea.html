Chapter 28 - Textarea in HTML

Understanding Textarea

The textarea element is a form control that enables users to input multiple lines of text. It's essential for collecting longer text content such as comments, messages, reviews, or any input that requires more than a single line. Unlike regular text inputs, textareas can be resized and support line breaks.

Styling Textarea

/* Basic styling */ textarea { padding: 10px; border: 1px solid #ccc; border-radius: 4px; font-family: inherit; font-size: 16px; } /* Resize options */ textarea { resize: none; /* Disable resizing */ resize: vertical; /* Only vertical */ resize: horizontal; /* Only horizontal */ resize: both; /* Both directions */ } /* Focus state */ textarea:focus { outline: none; border-color: #4CAF50; box-shadow: 0 0 5px rgba(76, 175, 80, 0.3); }

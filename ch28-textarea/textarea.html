Chapter 28 - Textarea in HTML5


What is a Textarea?

A textarea is an HTML form element that allows users to input multiple lines of text. It's commonly used for comments, reviews, messages, and any other input that requires more than a single line of text. The textarea is created using the "textarea" tag.


Basic Textarea Syntax

<textarea name="comment" rows="4" cols="50"> Enter your comment here... </textarea>

Textarea Attributes

The textarea element has several important attributes:

  • name - Specifies the name of the textarea (for form submission)
  • rows - Specifies the visible number of lines
  • cols - Specifies the visible width of the textarea
  • maxlength - Specifies the maximum number of characters allowed
  • placeholder - Specifies a short hint that describes the expected value
  • readonly - Specifies that the textarea should be read-only
  • disabled - Specifies that the textarea should be disabled
  • required - Specifies that the textarea must be filled out
  • autofocus - Specifies that the textarea should automatically get focus when the page loads

Styling Textarea

You can style a textarea using CSS to match your website's design:

textarea {
  width: 100%;
  padding: 12px;
  border: 1px solid #ccc;
  border-radius: 4px;
  resize: vertical; /* Allow vertical resizing */
}

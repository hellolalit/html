Chapter 17 - Embedding PDF Files in HTML


What is PDF Embedding?

Embedding PDF files in HTML allows you to display PDF documents directly within your web page, enabling users to view the content without downloading the file or opening it in a separate application. This can be particularly useful for displaying documents such as reports, brochures, user manuals, or any other content that is best presented in a PDF format.


Methods for Embedding PDF Files

There are several methods to embed PDF files in HTML. Let's explore the most common approaches:


1. Using the Object Element

The object element is a versatile way to embed PDFs and provides good browser compatibility:

<object
  data="document.pdf"
  type="application/pdf"
  width="800"
  height="600"
>
  <p>Your browser does not support PDFs.
  <a href="document.pdf">Download the PDF</a>.</p>
</object>

The content between the opening and closing object tags is displayed only if the browser cannot render the PDF.


2. Using the Embed Element

The embed element is a simpler, self-closing tag for embedding PDFs:

<embed
  src="document.pdf"
  type="application/pdf"
  width="800"
  height="600"
>

The embed element doesn't allow for fallback content, so it's best used when you're confident that your users' browsers support PDF embedding.


3. Using the Iframe Element

The iframe element can also be used to embed PDFs:

<iframe
  src="document.pdf"
  width="800"
  height="600"
  title="PDF Document"
>
  This browser does not support PDFs. Please download the PDF to view it:
  <a href="document.pdf">Download PDF</a>
</iframe>

Using iframes for PDFs provides good isolation from the rest of your page content.


Controlling PDF Display Options

You can control how the PDF is displayed by adding parameters to the URL. This works with the object, embed, and iframe elements:

<object
  data="document.pdf#page=2&zoom=50&toolbar=0&navpanes=0"
  type="application/pdf"
  width="800"
  height="600"
>
  <p>Your browser does not support PDFs.
  <a href="document.pdf">Download the PDF</a>.</p>
</object>

Common PDF URL Parameters

Parameter Description Example
page Specifies which page to display #page=4
zoom Sets the zoom level (in percentage) #zoom=75
toolbar Shows (1) or hides (0) the toolbar #toolbar=0
navpanes Shows (1) or hides (0) the navigation panes #navpanes=0
scrollbar Shows (1) or hides (0) the scrollbars #scrollbar=0
view Sets the view mode (Fit, FitH, FitV, etc.) #view=FitH

You can combine multiple parameters using the ampersand (&) symbol:

document.pdf#page=3&zoom=100&toolbar=0

Using Google Docs Viewer

For better cross-browser compatibility, you can use Google Docs Viewer to display PDFs:

<iframe
  src="https://docs.google.com/viewer?url=https://example.com/document.pdf&embedded=true"
  width="800"
  height="600"
  frameborder="0"
>
</iframe>

Note: The PDF must be accessible via a public URL for Google Docs Viewer to display it.


Using PDF.js

PDF.js is a JavaScript library developed by Mozilla that allows you to display PDFs in web browsers without relying on native PDF support:

<!-- Include PDF.js -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/pdf.js/2.11.338/pdf.min.js"></script>

<!-- PDF.js viewer container -->
<div id="pdf-container" style="width: 800px; height: 600px;"></div>

<script>
  // Set the worker source
  pdfjsLib.GlobalWorkerOptions.workerSrc = 'https://cdnjs.cloudflare.com/ajax/libs/pdf.js/2.11.338/pdf.worker.min.js';

  // Load the PDF
  const loadingTask = pdfjsLib.getDocument('document.pdf');
  loadingTask.promise.then(function(pdf) {
    // Get the first page
    pdf.getPage(1).then(function(page) {
      const scale = 1.5;
      const viewport = page.getViewport({ scale: scale });

      // Prepare canvas
      const container = document.getElementById('pdf-container');
      const canvas = document.createElement('canvas');
      const context = canvas.getContext('2d');
      canvas.width = viewport.width;
      canvas.height = viewport.height;
      container.appendChild(canvas);

      // Render PDF page
      const renderContext = {
        canvasContext: context,
        viewport: viewport
      };
      page.render(renderContext);
    });
  });
</script>

PDF.js provides more control over how PDFs are displayed and works in browsers that don't natively support PDF embedding.


Responsive PDF Embedding

To make embedded PDFs responsive, you can use CSS:

<style>
  .pdf-container {
    position: relative;
    width: 100%;
    height: 0;
    padding-bottom: 129.4%; /* Aspect ratio for A4 PDF */
    overflow: hidden;
  }

  .pdf-container object,
  .pdf-container embed,
  .pdf-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
  }
</style>

<div class="pdf-container">
  <object data="document.pdf" type="application/pdf">
    <p>Your browser does not support PDFs.
    <a href="document.pdf">Download the PDF</a>.</p>
  </object>
</div>

Accessibility Considerations

When embedding PDFs, consider these accessibility best practices:

  • Always provide a download link as an alternative
  • Ensure the PDF itself is accessible (contains proper headings, alt text for images, etc.)
  • Add a title attribute to iframe or object elements describing the PDF content
  • Consider providing a text summary of the PDF content on the page
  • Test the embedded PDF with screen readers and keyboard navigation

Security Considerations

When embedding PDFs, be aware of these security considerations:

  • Only embed PDFs from trusted sources
  • Consider using the sandbox attribute with iframes to restrict capabilities
  • Be cautious when embedding PDFs that contain JavaScript
  • Ensure that sensitive PDFs are properly protected and not publicly accessible

Browser Compatibility

PDF embedding support varies across browsers:

  • Chrome, Firefox, and Edge have built-in PDF viewers
  • Safari may open PDFs in a separate application or viewer
  • Mobile browsers have varying levels of support
  • Older browsers may not support PDF embedding at all

Always provide fallback options for browsers that don't support PDF embedding.

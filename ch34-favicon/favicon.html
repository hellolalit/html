Chapter 34 - Favicons in HTML5


What is a Favicon?

A favicon (short for "favorite icon") is a small icon associated with a website or web page. It appears in browser tabs, bookmarks, history, and other places where the website is referenced. Favicons help users identify your website visually and enhance brand recognition.


Basic Favicon Implementation

To add a favicon to your website, you need to create an icon file and link to it in the HTML head section. The most common format is .ico, but modern browsers also support PNG, GIF, and SVG formats.

<head>
  <title>My Website</title>
  <link rel="icon" type="image/x-icon" href="favicon.ico">
</head>

Different Favicon Formats

You can use different formats for your favicon:

  • ICO - Traditional format, supported by all browsers
  • PNG - Supports transparency, good for modern browsers
  • GIF - Supports animation, though animated favicons are rarely used
  • SVG - Vector format, scales well for different resolutions
<!-- ICO format -->
<link rel="icon" type="image/x-icon" href="favicon.ico">

<!-- PNG format -->
<link rel="icon" type="image/png" href="favicon.png">

<!-- SVG format -->
<link rel="icon" type="image/svg+xml" href="favicon.svg">

Multiple Favicon Sizes

For better compatibility across different devices and platforms, you can provide multiple favicon sizes. This is especially important for mobile devices and high-resolution displays.

<!-- Standard favicon -->
<link rel="icon" type="image/x-icon" href="favicon.ico">

<!-- iOS and Android icons -->
<link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png">
<link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png">

<!-- Android Chrome -->
<link rel="manifest" href="site.webmanifest">

Creating a Favicon

You can create a favicon using various tools:

  1. Graphic Design Software - Adobe Photoshop, Illustrator, or GIMP
  2. Online Favicon Generators - Websites like favicon.io, realfavicongenerator.net
  3. Icon Editors - Specialized software for creating icon files

When designing a favicon, keep it simple and recognizable even at small sizes (16x16 pixels). Use your logo or a simplified version of it that works well at small scales.


Favicon Best Practices

  • Keep the design simple and recognizable at small sizes
  • Provide multiple sizes for different devices and platforms
  • Use transparent backgrounds when appropriate
  • Test your favicon across different browsers and devices
  • Consider using SVG for scalable favicons
  • Place the favicon files in the root directory of your website for better discoverability

Browser Cache and Favicons

Browsers often cache favicons aggressively. If you update your favicon and don't see the changes, you might need to:

  • Clear your browser cache
  • Use a different filename for the new favicon
  • Add a version parameter to the favicon URL (e.g., favicon.ico?v=2)

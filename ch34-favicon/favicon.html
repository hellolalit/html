Chapter 34 - Favicons in HTML

Understanding Favicons

A favicon (short for "favorite icon") is a small icon associated with a website or web page. It appears in browser tabs, bookmarks, history, mobile home screens, and other places where the website is referenced. Favicons help users identify your website visually, enhance brand recognition, and improve the overall user experience.

Basic Implementation

<!-- Basic Favicon --> <head> <link rel="icon" type="image/x-icon" href="favicon.ico"> <!-- Alternative Formats --> <link rel="icon" type="image/png" href="favicon.png"> <link rel="icon" type="image/svg+xml" href="favicon.svg"> <!-- Apple Touch Icon --> <link rel="apple-touch-icon" href="apple-touch-icon.png"> <!-- Microsoft Tiles --> <meta name="msapplication-TileColor" content="#ffffff"> <meta name="msapplication-TileImage" content="ms-icon.png"> </head>

Responsive Favicons

<!-- Multiple Sizes for Different Devices --> <link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png"> <link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png"> <link rel="icon" type="image/png" sizes="48x48" href="favicon-48x48.png"> <!-- iOS Icons --> <link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png"> <link rel="apple-touch-icon" sizes="152x152" href="apple-touch-icon-152x152.png"> <link rel="apple-touch-icon" sizes="120x120" href="apple-touch-icon-120x120.png"> <!-- Android Icons --> <link rel="manifest" href="manifest.json"> <!-- Example manifest.json --> { "name": "My Website", "icons": [ { "src": "android-icon-192x192.png", "sizes": "192x192", "type": "image/png" }, { "src": "android-icon-512x512.png", "sizes": "512x512", "type": "image/png" } ] }

SVG Favicons

<!-- SVG Favicon --> <link rel="icon" type="image/svg+xml" href="favicon.svg"> <!-- Example SVG Favicon --> <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100"> <circle cx="50" cy="50" r="40" fill="#007bff"/> <text x="50" y="50" text-anchor="middle" dy=".3em" fill="white" font-size="50">A</text> </svg> <!-- PNG Fallback for Older Browsers --> <link rel="alternate icon" type="image/png" href="favicon.png">

Dynamic Favicons

// JavaScript for Dynamic Favicon function updateFavicon(status) { const favicon = document.querySelector('link[rel="icon"]'); switch(status) { case 'notification': favicon.href = 'favicon-notification.ico'; break; case 'offline': favicon.href = 'favicon-offline.ico'; break; default: favicon.href = 'favicon.ico'; } } // Example Usage updateFavicon('notification'); // Changes favicon to notification icon

Best Practices

  • Design - Keep it simple and recognizable at small sizes
  • Format Support - Provide multiple formats for compatibility
  • Responsive - Include various sizes for different devices
  • Placement - Store favicons in the root directory
  • Caching - Use versioning for updates
  • Testing - Verify across different browsers and devices

Troubleshooting

  • Clear browser cache after updates
  • Use versioning in favicon URLs (favicon.ico?v=2)
  • Verify file permissions and paths
  • Check server MIME type configuration
  • Test with different browsers
  • Validate manifest.json syntax

Chapter 9 - Images in HTML

Understanding HTML Images

Images are essential elements in web design, making content more engaging and informative. HTML provides the img element to embed images into web pages, along with various attributes to control how images are displayed and to provide alternative text for accessibility.

Basic Image Syntax

<img src="path/to/image.jpg" alt="Description of image">

Essential Image Attributes

  • src - The source URL of the image (required)
  • alt - Alternative text description (required for accessibility)
  • width - Image width in pixels
  • height - Image height in pixels
  • loading - Controls image loading behavior (lazy, eager)

Image File Types

  • JPEG/JPG - Best for photographs and complex images
  • PNG - Best for images with transparency or text
  • GIF - Best for simple animations
  • SVG - Best for logos and icons (scalable)
  • WebP - Modern format with better compression

Responsive Images

Make images responsive using the srcset and sizes attributes:

<img src="small.jpg" srcset="small.jpg 300w, medium.jpg 600w, large.jpg 900w" sizes="(max-width: 500px) 300px, (max-width: 900px) 600px, 900px" alt="Responsive image example">

Image as a Link

Wrap an image in an anchor tag to make it clickable:

<a href="large-version.jpg"> <img src="thumbnail.jpg" alt="Click to view larger image" width="150" height="150"> </a>

Figure and Figcaption

Use figure and figcaption elements for images with captions:

<figure> <img src="example.jpg" alt="Example image"> <figcaption> This is a caption for the image </figcaption> </figure>

Best Practices

  • Always use alt text - Crucial for accessibility
  • Optimize image sizes - Balance quality and load time
  • Choose appropriate formats - Use the right format for each use case
  • Specify dimensions - Helps prevent layout shifts
  • Use responsive images - For better mobile experience
  • Compress images - Reduce file size without losing quality
  • Consider lazy loading - Improve initial page load time

Common Use Cases

  1. Product photos in e-commerce
  2. Blog post featured images
  3. Company logos and branding
  4. Background images
  5. Image galleries
  6. User avatars and profiles
  7. Infographics and diagrams

Chapter 10 - Marquee and Modern Alternatives

Understanding Marquee

The marquee element was historically used to create scrolling text or content. However, it's important to note that the marquee element is deprecated and should not be used in modern web development. Instead, we'll learn about modern alternatives using CSS animations and JavaScript.

Historical Marquee Usage (Not Recommended)

<marquee>This text will scroll from right to left</marquee>

Modern Alternative: CSS Animation

Use CSS animations for scrolling text effects:

<div class="scroll-text"> This text will scroll smoothly </div> <style> .scroll-text { animation: scroll-left 20s linear infinite; white-space: nowrap; } @keyframes scroll-left { 0% { transform: translateX(100%); } 100% { transform: translateX(-100%); } } </style>

CSS Animation Properties

  • animation-name - Name of the @keyframes animation
  • animation-duration - How long the animation takes
  • animation-timing-function - Speed curve of the animation
  • animation-iteration-count - Number of times to run
  • animation-direction - Direction of animation

Modern Alternative: JavaScript

Create more interactive scrolling effects with JavaScript:

<div id="scroll-container"> <p id="scroll-text">This will scroll smoothly</p> </div> <script> const text = document.getElementById('scroll-text'); let position = window.innerWidth; function animate() { position--; text.style.transform = `translateX(${position}px)`; if (position < -text.offsetWidth) { position = window.innerWidth; } requestAnimationFrame(animate); } animate(); </script>

CSS Transform and Transition

For simpler hover effects that might have used marquee:

.hover-text { transition: transform 0.3s ease; } .hover-text:hover { transform: translateX(10px); }

Best Practices

  • Avoid marquee element - It's deprecated and not accessible
  • Use CSS animations - For simple scrolling effects
  • Consider JavaScript - For more complex animations
  • Respect user preferences - Check prefers-reduced-motion
  • Keep it subtle - Don't overuse animation effects
  • Ensure accessibility - Provide pause/stop controls

Modern Use Cases

  1. News tickers
  2. Announcement banners
  3. Social media feeds
  4. Stock tickers
  5. Event countdowns

Accessibility Considerations

@media (prefers-reduced-motion: reduce) { .scroll-text { animation: none; } }

Chapter 7 - Links in HTML

Understanding HTML Links

Links are the foundation of the World Wide Web, allowing users to navigate between web pages and resources. In HTML, links are created using the "a" (anchor) tag with its "href" attribute. Without links, the internet as we know it would not exist.

Basic Link Syntax

<a href="https://google.com">Google</a>

The HREF Attribute

The href (Hypertext Reference) attribute specifies the destination of a link. It can point to:

  • Web pages
  • Images
  • Videos
  • Documents
  • Sections within the same page

The Target Attribute

The target attribute controls how the linked content is displayed. Common values include:

  • _blank - Opens in a new window/tab
  • _self - Opens in the same frame (default)
  • _parent - Opens in the parent frame
  • _top - Opens in the full window body
  • framename - Opens in a specified frame

The Title Attribute

The title attribute provides additional information about the link, displayed when users hover over it. Example:

<a href="https://startpage.com" title="Privacy-focused search engine" target="_blank"> Startpage </a>

Local Links (Page Sections)

Local links allow navigation to specific sections within the same page using IDs:

<!-- Link to section --> <a href="#section-id">Go to Section</a> <!-- Target section --> <h2 id="section-id">Section Title</h2>

Linking Images

Images can be made clickable by wrapping them in an anchor tag:

<a href="image.jpg"> <img src="thumbnail.jpg" alt="Click to view full image" width="150" height="150"> </a>

Best Practices

  • Use descriptive text - Make link text meaningful
  • Consider accessibility - Add title attributes for context
  • Check links - Ensure all links work and point to correct destinations
  • Style consistently - Make links visually distinct
  • Use relative paths - For internal links within your site

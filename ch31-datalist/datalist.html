Chapter 31 - Datalist in HTML5


What is a Datalist?

The datalist element provides a list of predefined options for an input element. It creates an autocomplete feature that allows users to select from a dropdown list of options while still being able to enter their own value. The datalist element is one of the new form elements introduced in HTML5.


Basic Datalist Syntax

<input list="browsers" name="browser">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
  <option value="Edge">
</datalist>

How Datalist Works

To use a datalist:

  1. Create an input element with a list attribute
  2. Create a datalist element with an id that matches the input's list attribute
  3. Add option elements inside the datalist

The input element will display a dropdown of suggestions from the datalist when the user starts typing. The user can either select one of the suggestions or enter a completely different value.

Datalist with Different Input Types

Datalists can be used with different input types, not just text:

<!-- With color input -->
<input type="color" list="colors" name="color">
<datalist id="colors">
  <option value="#ff0000">
  <option value="#00ff00">
  <option value="#0000ff">
</datalist>

<!-- With range input -->
<input type="range" list="tickmarks" min="0" max="100">
<datalist id="tickmarks">
  <option value="0">
  <option value="25">
  <option value="50">
  <option value="75">
  <option value="100">
</datalist>

Advantages of Datalist

  • Provides suggestions while still allowing free input
  • Improves user experience by reducing typing and errors
  • Works with various input types
  • Lightweight alternative to JavaScript autocomplete libraries

Browser Support

The datalist element is supported in all modern browsers, but it may not work in older browsers. It's always a good idea to provide a fallback for browsers that don't support datalist.

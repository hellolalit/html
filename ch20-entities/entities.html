Chapter 20 - HTML Entities


What are HTML Entities?

HTML entities are special codes used to represent characters that have special meaning in HTML or characters that are difficult to type directly. They allow you to display characters that might otherwise be interpreted as HTML code or characters that aren't available on your keyboard.

HTML entities begin with an ampersand (&) and end with a semicolon (;). They can be written in two forms:

  • Named entities: Use a descriptive name (e.g., &lt; for the less-than sign)
  • Numeric entities: Use the character's Unicode code point, either in decimal (e.g., &#60;) or hexadecimal (e.g., &#x3C;)

Why Use HTML Entities?

There are several reasons to use HTML entities:

  1. To display reserved characters that have special meaning in HTML (like <, >, &)
  2. To display characters not available on your keyboard
  3. To display invisible or non-printing characters
  4. To ensure proper rendering across different browsers and character encodings
  5. To avoid conflicts with character encoding issues

Space Entities

HTML collapses multiple spaces into a single space when rendering. To add extra spaces, you can use space entities:

Entity Description Width
&nbsp; Non-breaking space Width of a normal space
&ensp; En space Width of half an em (N)
&emsp; Em space Width of one em (M)
&thinsp; Thin space Width of 1/6 of an em

Example of using space entities:

<p>Normal&nbsp;space</p>
<p>En&ensp;space</p>
<p>Em&emsp;space</p>
<p>Thin&thinsp;space</p>

Using HTML Entities in Code

Here are some examples of using HTML entities in your code:

<!-- Displaying reserved characters -->
<p>The &lt;div&gt; tag is used to create a division or section in HTML.</p>

<!-- Using non-breaking spaces to keep words together -->
<p>Mr.&nbsp;Smith will not wrap to the next line.</p>

<!-- Using copyright symbol -->
<footer>&copy; 2023 My Website. All rights reserved.</footer>

<!-- Using mathematical symbols -->
<p>The area of a circle is &pi;r&sup2;.</p>

<!-- Using arrows -->
<p>Click here &rarr; to continue.</p>

Best Practices for Using HTML Entities

When working with HTML entities, keep these best practices in mind:

  1. Use named entities when available - They're more readable and easier to remember than numeric entities.
  2. Always include the semicolon - While some browsers might render entities without the semicolon, it's required for valid HTML.
  3. Use UTF-8 encoding - With UTF-8 encoding, many special characters can be typed directly without entities, but entities ensure consistent rendering across all browsers.
  4. Consider accessibility - Ensure that the use of special characters doesn't impact screen readers or other assistive technologies.
  5. Be consistent - If you use entities for special characters, do so consistently throughout your site.

Character Encoding and HTML Entities

HTML entities are closely related to character encoding. The character encoding of your HTML document (specified in the meta charset tag) determines which characters can be displayed directly and which need to be represented as entities.

With UTF-8 encoding (the recommended encoding for HTML5), most special characters can be typed directly without using entities. However, entities are still necessary for reserved characters like <, >, and &, and they provide a reliable way to ensure characters display correctly across all browsers and devices.

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Character Encoding Example</title>
</head>
<body>
  <p>Direct special characters: € £ ¥ © ®</p>
  <p>Entity special characters: &euro; &pound; &yen; &copy; &reg;</p>
</body>
</html>

With UTF-8 encoding, both approaches will display the same characters, but entities provide better cross-browser compatibility.

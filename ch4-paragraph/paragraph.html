Chapter 4 - Paragraphs in HTML

Understanding HTML Paragraphs

Paragraphs are fundamental building blocks of web content. In HTML, paragraphs are block-level elements used to group related content, typically text. They provide proper spacing and structure to make content more readable and organized.

Basic Paragraph Syntax

<p>
  This is a paragraph. It can contain text,
  links, images, and other inline elements.
</p>

Line Breaks (BR Tag)

The <br> tag creates a line break within text. Unlike paragraphs, it doesn't add extra spacing:

This is line one<br>
This is line two<br>
This is line three

Preformatted Text (PRE Tag)

The <pre> tag preserves both spaces and line breaks, making it perfect for displaying code or formatted text: 

function sayHello() {
    console.log("Hello!");
}

// This text keeps its formatting
    Including spaces
    and line breaks

Horizontal Rules (HR Tag)

The <hr> tag creates a thematic break, visually represented as a horizontal line:

<p>Section one</p>
<hr>
<p>Section two</p>

Example with HR Tag

This is section one

This is section two

Best Practices

  • Use paragraphs semantically: Group related content together
  • Avoid empty paragraphs: Use margins/padding for spacing
  • Use <br> sparingly: Prefer CSS for layout control
  • Keep paragraphs focused: Each paragraph should express one main idea
  • Consider readability: Keep paragraphs reasonably short

Common Uses

  1. Article and blog post content
  2. Product descriptions
  3. About pages
  4. Documentation
  5. News articles

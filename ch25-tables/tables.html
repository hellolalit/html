Chapter 25 - HTML Tables

Understanding HTML Tables

HTML tables are used to organize data into rows and columns, making it easier to present structured information. Tables should be used for tabular data only, not for layout purposes. Modern CSS grid and flexbox are better suited for page layouts.

Basic Table Structure

<table> <caption>Monthly Budget</caption> <thead> <tr> <th>Category</th> <th>Amount</th> </tr> </thead> <tbody> <tr> <td>Rent</td> <td>$1000</td> </tr> <tr> <td>Utilities</td> <td>$200</td> </tr> </tbody> <tfoot> <tr> <th>Total</th> <td>$1200</td> </tr> </tfoot> </table>

Table Elements

<table> - Container for the table <caption> - Table title/description <thead> - Header section <tbody> - Main content section <tfoot> - Footer section <tr> - Table row <th> - Header cell <td> - Data cell <colgroup> - Column group <col> - Column properties

Table Attributes

colspan - Span multiple columns rowspan - Span multiple rows headers - Associated header cells scope - Header's scope (row/col) role="table" - Table role aria-label - Table description aria-describedby - Related description

Complex Tables

<table> <caption>Quarterly Sales Report</caption> <colgroup> <col class="product"> <col span="4" class="quarterly-data"> </colgroup> <thead> <tr> <th rowspan="2" scope="col">Product</th> <th colspan="4" scope="colgroup">Quarterly Sales</th> </tr> <tr> <th scope="col">Q1</th> <th scope="col">Q2</th> <th scope="col">Q3</th> <th scope="col">Q4</th> </tr> </thead> <tbody> <tr> <th scope="row">Product A</th> <td>$100</td> <td>$150</td> <td>$200</td> <td>$250</td> </tr> </tbody> </table>

Styling Tables

/* Basic table styling */ table { border-collapse: collapse; width: 100%; } th, td { padding: 8px; text-align: left; border: 1px solid #ddd; } /* Zebra striping */ tbody tr:nth-child(even) { background-color: #f2f2f2; } /* Hover effect */ tbody tr:hover { background-color: #ddd; } /* Responsive tables */ .table-container { overflow-x: auto; }

Best Practices

  • Use semantic markup - Proper table structure
  • Add captions - Clear table descriptions
  • Use headers - Proper th elements
  • Consider responsiveness - Mobile-friendly tables
  • Maintain accessibility - ARIA labels and scope
  • Keep it simple - Avoid complex nested tables

Common Use Cases

  • Data presentation
  • Financial reports
  • Schedule displays
  • Product comparisons
  • Statistical data
  • Sports results

Accessibility Considerations

  • Use proper header cells
  • Add scope attributes
  • Provide table summaries
  • Use caption elements
  • Mark up complex relationships
  • Test with screen readers

Chapter 19 - Embedding Google Maps in HTML


Introduction to Google Maps Embedding

Embedding Google Maps in your HTML pages allows you to display interactive maps directly on your website. This can be useful for showing business locations, event venues, travel routes, or any other geographic information that would benefit from a visual representation. Google provides several methods for embedding maps, from simple iframe embeds to more advanced JavaScript API implementations.


Basic Google Maps Embed

The simplest way to embed a Google Map is to use the iframe element with Google Maps' embed URL:

<iframe
  src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d3022.215573117898!2d-73.98784532418936!3d40.75798833440443!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x89c25855c6480299%3A0x55194ec5a1ae072e!2sTimes%20Square!5e0!3m2!1sen!2sus!4v1710000000000!5m2!1sen!2sus"
  width="600"
  height="450"
  style="border:0;"
  allowfullscreen=""
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"
></iframe>

Getting the Embed Code from Google Maps

The easiest way to get the correct embed code is directly from Google Maps:

  1. Go to Google Maps
  2. Search for the location you want to embed
  3. Click on the "Share" button (the paper airplane icon)
  4. Select the "Embed a map" tab
  5. Choose your desired map size
  6. Copy the provided iframe code
  7. Paste the code into your HTML document

Customizing the Embedded Map

You can customize the embedded map by modifying the iframe attributes:

  • width and height: Set the dimensions of the map
  • style: Add CSS styling (e.g., border, margin)
  • loading="lazy": Defers loading the map until it's near the viewport
  • referrerpolicy: Controls what referrer information is passed

You can also customize the map itself by modifying the URL parameters in the src attribute, though this is more complex and less reliable than using the Google Maps embed tool.


Responsive Google Maps Embed

To make the embedded map responsive (adapt to different screen sizes), you can use CSS:

<style>
  .map-container {
    position: relative;
    padding-bottom: 75%; /* 4:3 Aspect Ratio */
    height: 0;
    overflow: hidden;
    max-width: 100%;
  }

  .map-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
  }
</style>

<div class="map-container">
  <iframe

    style="border:0;"

This CSS creates a responsive container that maintains a 4:3 aspect ratio at any screen size. You can adjust the padding-bottom percentage to change the aspect ratio.


Google Maps Embed Types

Google Maps offers several types of embeds:

Embed Type Description
Place Shows a specific location with a marker
Directions Shows a route between two locations
Search Shows search results for a query
View Shows a map centered at specific coordinates
Streetview Shows a Street View panorama

Each type can be selected when generating the embed code through Google Maps.

Google Maps JavaScript API

For more advanced map functionality, you can use the Google Maps JavaScript API. This requires an API key from the Google Cloud Platform.

<!-- HTML container for the map -->
<div id="map" style="height: 400px; width: 100%;"></div>

<!-- JavaScript for the map -->
<script>
  // Initialize and add the map
  function initMap() {
    // The location of Times Square
    const timesSquare = { lat: 40.7580, lng: -73.9855 };
    // The map, centered at Times Square
    const map = new google.maps.Map(document.getElementById("map"), {
      zoom: 15,
      center: timesSquare,
    });
    // The marker, positioned at Times Square
    const marker = new google.maps.Marker({
      position: timesSquare,
      map: map,
      title: "Times Square",
    });
  }
</script>

<!-- Load the Google Maps JavaScript API -->
<script
  src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&callback=initMap"
  async
  defer
></script>

Replace YOUR_API_KEY with your actual Google Maps API key. The JavaScript API offers more customization options than the iframe embed, including:

  • Custom markers and info windows
  • Drawing tools and shapes
  • Heatmaps and data visualization
  • Geocoding and directions
  • Custom map styles
  • User interaction handling

Adding Custom Markers and Info Windows

<script>
  function initMap() {
    const map = new google.maps.Map(document.getElementById("map"), {
      zoom: 14,
      center: { lat: 40.7580, lng: -73.9855 },
    });

    // Array of marker positions and info
    const locations = [
      {
        position: { lat: 40.7580, lng: -73.9855 },
        title: "Times Square",
        content: "<h3>Times Square</h3><p>The bustling heart of Manhattan.</p>"
      },
      {
        position: { lat: 40.7484, lng: -73.9857 },
        title: "Empire State Building",
        content: "<h3>Empire State Building</h3><p>Iconic skyscraper in Midtown Manhattan.</p>"
      },
      {
        position: { lat: 40.7587, lng: -73.9787 },
        title: "Rockefeller Center",
        content: "<h3>Rockefeller Center</h3><p>Complex of commercial buildings in Midtown.</p>"
      }
    ];

    // Create an info window
    const infoWindow = new google.maps.InfoWindow();

    // Create markers and add click listeners
    locations.forEach((location) => {
      const marker = new google.maps.Marker({
        position: location.position,
        map: map,
        title: location.title,
      });

      marker.addListener("click", () => {
        infoWindow.close();
        infoWindow.setContent(location.content);
        infoWindow.open(map, marker);
      });
    });
  }
</script>

Custom Map Styles

You can customize the appearance of your map using the Google Maps JavaScript API:

<script>
  function initMap() {
    // Custom map style
    const darkStyle = [
      { elementType: "geometry", stylers: [{ color: "#242f3e" }] },
      { elementType: "labels.text.stroke", stylers: [{ color: "#242f3e" }] },
      { elementType: "labels.text.fill", stylers: [{ color: "#746855" }] },
      {
        featureType: "administrative.locality",
        elementType: "labels.text.fill",
        stylers: [{ color: "#d59563" }],
      },
      // More style rules...
    ];

    // Create the map with custom style
    const map = new google.maps.Map(document.getElementById("map"), {
      center: { lat: 40.7580, lng: -73.9855 },
      zoom: 15,
      styles: darkStyle,
    });
  }
</script>

You can create custom map styles using the Google Maps Styling Wizard and export the JSON for use in your code.


Accessibility Considerations

When embedding Google Maps, consider these accessibility best practices:

  • Provide a text description or address information alongside the map
  • Add a title attribute to the iframe describing the map content
  • Ensure keyboard navigation works with the embedded map
  • Consider providing alternative directions or location information for users who cannot use the map
  • Use appropriate color contrast for any custom map styles

Performance Considerations

Embedded maps can impact page load times. Consider these performance tips:

  • Use the loading="lazy" attribute to defer loading until the map is near the viewport
  • Set an appropriate size for the map to reduce initial load time
  • Consider loading the map only after a user interaction (like clicking a button)
  • Limit the number of markers and features on a single map
  • Use the async and defer attributes when loading the Google Maps JavaScript API

Privacy and Terms of Use

When using Google Maps on your website, be aware of the following:

  • Google Maps Platform is subject to the Google Maps Platform Terms of Service
  • You must comply with Google's terms of use and privacy policies
  • For the JavaScript API, you need to create a billing account (though there is a generous free tier)
  • You should include appropriate privacy notices if your site collects user location data

Chapter 15 - Audio in HTML5


What is the Audio Element?

The HTML5 audio element is used to embed sound content in web pages. It provides a standard way to include audio on your website without requiring third-party plugins like Flash. The audio element supports various audio formats and offers controls for playback, volume adjustment, and more.


Basic Audio Syntax

<audio src="audio-file.mp3" controls></audio>

Audio Attributes

The audio element supports several attributes to control its behavior:

  • src - Specifies the URL of the audio file
  • controls - Displays the default audio controls (play/pause, volume, etc.)
  • autoplay - Starts playing the audio automatically when the page loads
  • loop - Plays the audio repeatedly
  • muted - Mutes the audio output
  • preload - Specifies if and how the audio should be loaded when the page loads

Example with Controls

Here's an example of an audio element with controls:

<audio src="music.mp3" controls>
  Your browser does not support the audio element.
</audio>

Note: The text between the opening and closing audio tags is displayed only if the browser doesn't support the audio element.


Supported Audio Formats

Different browsers support different audio formats. The main formats used with the audio element are:

Format File Extension MIME Type Browser Support
MP3 .mp3 audio/mpeg All modern browsers
WAV .wav audio/wav All modern browsers except IE
OGG .ogg audio/ogg Chrome, Firefox, Opera
AAC .aac audio/aac Chrome, Safari

Multiple Source Formats

To ensure cross-browser compatibility, you can provide multiple audio sources using the source element:

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  <source src="audio.wav" type="audio/wav">
  Your browser does not support the audio element.
</audio>

The browser will use the first recognized format in the list.


Autoplay Attribute

The autoplay attribute starts playing the audio automatically when the page loads:

<audio src="background-music.mp3" autoplay></audio>

Note: Many modern browsers block autoplay with sound to improve user experience. To autoplay audio, you may need to also include the muted attribute or start playback in response to a user action.


Loop Attribute

The loop attribute makes the audio play repeatedly:

<audio src="background-music.mp3" loop></audio>

Preload Attribute

The preload attribute specifies if and how the audio should be loaded when the page loads:

<!-- No preloading (saves bandwidth) -->
<audio src="large-file.mp3" preload="none" controls></audio>

<!-- Preload metadata only (size, first frame, etc.) -->
<audio src="music.mp3" preload="metadata" controls></audio>

<!-- Preload the entire audio file -->
<audio src="short-clip.mp3" preload="auto" controls></audio>

Styling Audio Controls

The default audio controls can be styled to some extent using CSS, but the styling options are limited. For complete control over the appearance, you can create custom controls using JavaScript:

<!-- HTML -->
<audio id="myAudio" src="music.mp3"></audio>
<div class="custom-audio-controls">
  <button onclick="document.getElementById('myAudio').play()">Play</button>
  <button onclick="document.getElementById('myAudio').pause()">Pause</button>
  <input type="range" id="volume" min="0" max="1" step="0.1" value="1"
    oninput="document.getElementById('myAudio').volume = this.value">
</div>

JavaScript Audio API

HTML5 also provides a powerful JavaScript API for controlling audio playback:

<script>
  // Get the audio element
  const audio = document.getElementById('myAudio');

  // Play the audio
  function playAudio() {
    audio.play();
  }

  // Pause the audio
  function pauseAudio() {
    audio.pause();
  }

  // Set the volume (0.0 to 1.0)
  function setVolume(volume) {
    audio.volume = volume;
  }

  // Skip to a specific time (in seconds)
  function skipTo(time) {
    audio.currentTime = time;
  }

  // Event listeners
  audio.addEventListener('play', function() {
    console.log('Audio started playing');
  });

  audio.addEventListener('ended', function() {
    console.log('Audio playback finished');
  });
</script>

Background Audio

For background audio that doesn't need controls, you can hide the audio element:

<audio src="background-music.mp3" autoplay loop></audio>

Remember that autoplay with sound is often blocked by browsers unless the user has interacted with the page.


Accessibility Considerations

When using audio on your website, consider these accessibility best practices:

  • Always provide controls so users can control playback
  • Avoid autoplay with sound, as it can be disruptive
  • Provide transcripts or captions for audio content
  • Ensure audio controls are keyboard accessible
  • Don't rely solely on sound to convey important information

Audio File Size and Performance

Audio files can be large and impact page loading times. Consider these tips:

  • Use compressed formats like MP3 with appropriate bitrates
  • Consider using the preload="none" or preload="metadata" attributes for large files
  • Use a content delivery network (CDN) for faster delivery
  • Consider streaming for very large audio files

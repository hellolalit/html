Chapter 15 - Audio in HTML

Understanding HTML Audio

The HTML audio element provides a standard way to embed sound content in web pages without requiring third-party plugins. It supports various audio formats and offers built-in controls for playback, volume adjustment, and more.

Basic Audio Syntax

<audio src="audio-file.mp3" controls> Your browser does not support the audio element. </audio>

Audio Formats

  • MP3 (.mp3) - Most widely supported
  • WAV (.wav) - High quality, uncompressed
  • OGG (.ogg) - Free, open container format
  • AAC (.aac) - Advanced Audio Coding

Multiple Source Support

<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> <source src="audio.wav" type="audio/wav"> Your browser does not support the audio element. </audio>

Essential Attributes

  • src - URL of the audio file
  • controls - Shows playback controls
  • autoplay - Starts playing automatically
  • loop - Repeats the audio
  • muted - Sets initial muted state
  • preload - Loading behavior (auto/metadata/none)

JavaScript Audio API

const audio = document.querySelector('audio'); // Play audio audio.play(); // Pause audio audio.pause(); // Set volume (0.0 to 1.0) audio.volume = 0.5; // Set playback time audio.currentTime = 30; // Skip to 30 seconds // Check if audio is playing const isPlaying = !audio.paused;

Custom Audio Player

<div class="audio-player"> <audio id="myAudio" src="audio.mp3"></audio> <button onclick="document.getElementById('myAudio').play()"> Play </button> <button onclick="document.getElementById('myAudio').pause()"> Pause </button> <input type="range" min="0" max="1" step="0.1" value="1" onchange="document.getElementById('myAudio').volume = this.value"> </div>

Best Practices

  • Provide multiple formats - Ensure broad browser support
  • Include fallback content - Handle unsupported cases
  • Consider autoplay policies - Many browsers block autoplay
  • Optimize file sizes - Use appropriate compression
  • Add transcripts - Improve accessibility
  • Use preload wisely - Balance performance and bandwidth

Accessibility Considerations

  • Provide transcripts for audio content
  • Use ARIA labels for custom controls
  • Ensure keyboard navigation works
  • Consider auto-pause when content is hidden
  • Provide visual feedback for audio state

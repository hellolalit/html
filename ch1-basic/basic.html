Chapter 1 - Basics of HTML

Basic TAGS of HTML5

  1. The DOCTYPE

    The "DOCTYPE" is neither an HTML tag nor an element. It is used to tell the browser what version of HTML5 is used. This "DOCTYPE" should be declared at the first line of an HTML5 document.
    There are more than 1 DOCTYPES such as SVG and MathML.

  2. HTML TAG

    HTML Tag is the 'root' element of an HTML document which means the HTML document starts with an HTML tag and ends with the same HTML tag. The HTML tag is the container for all other HTML elements (except for the !DOCTYPE declaration).

  3. HEAD TAG

    HEAD Tag is used to tell the computer that the heading content of the document is present inside the HEAD tag.
    It mainly includes meta tags, link tags, title tag and other important tags within it. HEAD tag is used by browsers to add information to the search page like the heading and description of the website.

  4. TITLE TAG

    TITLE Tag is used to define the title of the website/webpage.

  5. BODY TAG

    BODY Tag is used to define the body of the HTML document.
    The closing of the tag tells the computer that specific line is the end of that body tag and the body of the HTML5 document ends at that specific line.

  6. SCRIPT TAG

    SCRIPT Tag is used to link Javascript files to the HTML5 document.

Chapter 30 - Radio Buttons and Checkboxes in HTML

Understanding Radio Buttons and Checkboxes

Radio buttons and checkboxes are form controls that allow users to make selections. Radio buttons enable single selection within a group, while checkboxes allow multiple selections. Both elements are created using the input element with different type attributes and serve distinct purposes in form design.

type - "radio" or "checkbox" name - Group identifier value - Selected value id - Unique identifier checked - Default selection required - Required selection disabled - Disable input readonly - Read-only state onclick - Click event onchange - Change event onfocus - Focus event onblur - Blur event

Advanced Features

Styling Radio Buttons and Checkboxes

/* Basic styling */ input[type="radio"], input[type="checkbox"] { margin-right: 8px; cursor: pointer; } /* Custom appearance */ .custom-radio, .custom-checkbox { appearance: none; width: 20px; height: 20px; border: 2px solid #ccc; border-radius: 50%; /* for radio */ border-radius: 4px; /* for checkbox */ } /* Checked state */ .custom-radio:checked, .custom-checkbox:checked { background-color: #4CAF50; border-color: #4CAF50; } /* Focus state */ .custom-radio:focus, .custom-checkbox:focus { outline: none; box-shadow: 0 0 0 2px rgba(76, 175, 80, 0.3); }

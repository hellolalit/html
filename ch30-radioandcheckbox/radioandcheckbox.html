Chapter 30 - Radio Buttons and Checkboxes in HTML5


What are Radio Buttons and Checkboxes?

Radio buttons and checkboxes are form elements that allow users to select options. The key difference is that radio buttons allow selecting only one option from a group, while checkboxes allow selecting multiple options. Both are created using the input element with different type attributes.


Radio Buttons

Radio buttons are created using <input type="radio">. Radio buttons with the same name attribute form a group, and only one option in the group can be selected at a time.

<input type="radio" id="male" name="gender" value="male">
<label for="male">Male</label>
<input type="radio" id="female" name="gender" value="female">
<label for="female">Female</label>

Checkboxes

Checkboxes are created using <input type="checkbox">. Multiple checkboxes can be selected at the same time, even if they share the same name attribute.

<input type="checkbox" id="vehicle1" name="vehicle" value="bike">
<label for="vehicle1">I have a bike</label>
<input type="checkbox" id="vehicle2" name="vehicle" value="car">
<label for="vehicle2">I have a car</label>

Radio Button and Checkbox Attributes

Both radio buttons and checkboxes share these common attributes:

  • name - Specifies the name of the input element (for form submission)
  • value - Specifies the value to be sent to the server when the form is submitted
  • checked - Specifies that the input element should be pre-selected when the page loads
  • disabled - Specifies that the input element should be disabled
  • required - Specifies that the input element must be checked

Styling Radio Buttons and Checkboxes

You can style radio buttons and checkboxes using CSS, but it can be challenging due to browser inconsistencies. Many developers use custom styling with CSS or JavaScript libraries.

Chapter 2 - Comments in HTML

What are HTML Comments?

HTML comments are notes that can be added to the HTML code but are not displayed in the browser. They are useful for documenting your HTML code, making it easier to understand and maintain.

Comment Syntax

Comments in HTML start with <!-- and end with -->. Everything between these markers is ignored by the browser.

<!-- This is a comment -->
<!--
  This is a multi-line comment
  It can span multiple lines
-->

Uses of Comments

  1. Documentation: Explain what different parts of your code do
  2. Debugging: Temporarily disable parts of your code
  3. Organization: Mark sections of your HTML document
  4. Communication: Leave notes for other developers

Example with Comments

<!-- Header section -->
<header>
  <h1>My Website</h1>
</header>

<!-- Navigation menu -->
<nav>
  <!-- TODO: Add more menu items -->
  <ul>
    <li>Home</li>
    <li>About</li>
  </ul>
</nav>

Best Practices

  • Keep comments clear and concise
  • Use comments to explain complex code sections
  • Update comments when you update code
  • Don't overuse comments - let your code be self-documenting
  • Remove debugging comments before deploying

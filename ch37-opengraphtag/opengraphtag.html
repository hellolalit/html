Chapter 37 - Open Graph Tags in HTML5


What are Open Graph Tags?

Open Graph (OG) is a protocol that enables any web page to become a rich object in a social graph. It was originally created by Facebook in 2010 to enable web pages to have the same functionality as other Facebook objects. When you share a link on social media platforms like Facebook, Twitter, or LinkedIn, Open Graph meta tags determine how your content appears in the shared post.


Basic Open Graph Tags

Open Graph meta tags are placed in the head section of your HTML document. They use the property attribute instead of the name attribute used by standard meta tags. Here are the basic Open Graph tags:

<head>
  <title>My Website</title>
  <meta property="og:title" content="My Website Title">
  <meta property="og:description" content="Description of my website">
  <meta property="og:image" content="https://example.com/image.jpg">
  <meta property="og:url" content="https://example.com">
  <meta property="og:type" content="website">
</head>

Core Open Graph Properties

  • og:title - The title of your page
  • og:description - A brief description of your content
  • og:image - The URL of an image to represent your content
  • og:url - The canonical URL of your page
  • og:type - The type of content (e.g., website, article, video)
  • og:site_name - The name of your website

Open Graph Types

The og:type property specifies the type of content you're sharing. Here are some common types:

  • website - A generic website
  • article - An article or blog post
  • book - A book
  • profile - A person's profile
  • music.song - A song
  • music.album - A music album
  • video.movie - A movie
  • video.tv_show - A TV show

Additional Open Graph Tags for Articles

If your content is an article, you can use additional tags:

<meta property="og:type" content="article">
<meta property="article:published_time" content="2023-05-15T08:00:00+00:00">
<meta property="article:author" content="https://example.com/author">
<meta property="article:section" content="Technology">
<meta property="article:tag" content="HTML">
<meta property="article:tag" content="Open Graph">

Image Recommendations

For optimal display across different platforms, follow these image recommendations:

  • Use images that are at least 1200 x 630 pixels for best display on high-resolution devices
  • Maintain an aspect ratio of 1.91:1
  • Keep the file size under 8MB
  • Use PNG, JPEG, or GIF format

You can also specify multiple images with different sizes:

<meta property="og:image" content="https://example.com/image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Description of the image">

Testing Open Graph Tags

You can test how your Open Graph tags will appear when shared using these tools:

  • Facebook Sharing Debugger
  • Twitter Card Validator
  • LinkedIn Post Inspector

Benefits of Using Open Graph Tags

  • Improved visibility and engagement when your content is shared on social media
  • Control over how your content appears when shared
  • Higher click-through rates from social media platforms
  • Better brand recognition with consistent imagery

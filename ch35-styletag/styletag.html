Chapter 35 - Style Tag in HTML5


What is the Style Tag?

The style tag is used to define internal CSS (Cascading Style Sheets) within an HTML document. It allows you to specify how HTML elements should be displayed directly within the HTML file, without requiring an external CSS file. The style tag is typically placed in the head section of the HTML document.


Basic Syntax

<head>
  <title>My Website</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      margin: 0;
      padding: 20px;
    }
    h1 {
      color: #3498db;
    }
  </style>
</head>

Style Tag Attributes

The style tag has a few attributes:

  • type - Specifies the MIME type of the style sheet (default is "text/css")
  • media - Specifies what media/device the media resource is optimized for
  • nonce - A cryptographic nonce used with Content Security Policy
<style type="text/css" media="screen">
  /* CSS rules here */
</style>

Media Attribute Example

The media attribute allows you to specify different styles for different devices or screen sizes:

<!-- Styles for print -->
<style media="print">
  body {
    font-size: 12pt;
    color: black;
  }
</style>

<!-- Styles for screens smaller than 600px -->
<style media="screen and (max-width: 600px)">
  body {
    font-size: 14px;
  }
</style>

CSS Selectors in Style Tag

Within the style tag, you can use various CSS selectors to target specific HTML elements:

<style>
  /* Element selector */
  h1 {
    color: blue;
  }

  /* Class selector */
  .highlight {
    background-color: yellow;
  }

  /* ID selector */
  #header {
    font-size: 24px;
  }

  /* Descendant selector */
  nav a {
    text-decoration: none;
  }
</style>

Internal vs. External CSS

There are three ways to add CSS to HTML:

  1. Internal CSS - Using the style tag in the head section
  2. External CSS - Linking to an external .css file using the link tag
  3. Inline CSS - Using the style attribute directly on HTML elements
<!-- Internal CSS -->
<style>
  p { color: blue; }
</style>

<!-- External CSS -->
<link rel="stylesheet" href="styles.css">

<!-- Inline CSS -->
<p style="color: blue;">This is a blue paragraph.</p>

When to Use the Style Tag

The style tag is useful in several scenarios:

  • For small websites with minimal CSS
  • When you need page-specific styles that aren't used elsewhere
  • For prototyping or testing styles before moving them to an external file
  • When you want to reduce HTTP requests by not loading an external CSS file

However, for larger websites, external CSS files are generally preferred for better organization, maintainability, and caching benefits.

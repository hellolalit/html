Chapter 16 - Video in HTML

Understanding HTML Video

The HTML video element provides a standard way to embed video content in web pages without requiring third-party plugins. It supports various video formats and offers built-in controls for playback, volume adjustment, fullscreen viewing, and more.

Basic Video Syntax

<video src="video.mp4" controls width="640" height="360"> Your browser does not support the video element. </video>

Video Formats

  • MP4 (.mp4) - Most widely supported (H.264)
  • WebM (.webm) - Open format, good compression
  • OGV (.ogv) - Open format Ogg container

Multiple Source Support

<video controls width="640" height="360"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> <source src="video.ogv" type="video/ogg"> Your browser does not support the video element. </video>

Essential Attributes

  • src - URL of the video file
  • controls - Shows playback controls
  • width - Video player width
  • height - Video player height
  • autoplay - Starts playing automatically
  • loop - Repeats the video
  • muted - Sets initial muted state
  • poster - Thumbnail image URL
  • preload - Loading behavior (auto/metadata/none)
  • playsinline - Play inline on iOS

JavaScript Video API

const video = document.querySelector('video'); // Play video video.play(); // Pause video video.pause(); // Set volume (0.0 to 1.0) video.volume = 0.5; // Set playback time video.currentTime = 30; // Skip to 30 seconds // Toggle fullscreen video.requestFullscreen(); // Set playback rate video.playbackRate = 1.5; // 1.5x speed // Check if video is playing const isPlaying = !video.paused;

Custom Video Player

<div class="video-player"> <video id="myVideo" src="video.mp4"></video> <div class="controls"> <button onclick="document.getElementById('myVideo').play()"> Play </button> <button onclick="document.getElementById('myVideo').pause()"> Pause </button> <input type="range" class="timeline" min="0" max="100" step="0.1" onchange="seekVideo(this.value)"> <button onclick="toggleFullscreen()"> Fullscreen </button> <input type="range" class="volume" min="0" max="1" step="0.1" value="1" onchange="setVolume(this.value)"> </div> </div>

Responsive Video

.video-container { position: relative; width: 100%; padding-bottom: 56.25%; /* 16:9 Aspect Ratio */ } .video-container video { position: absolute; top: 0; left: 0; width: 100%; height: 100%; }

Best Practices

  • Provide multiple formats - Ensure broad browser support
  • Include fallback content - Handle unsupported cases
  • Set width and height - Prevent layout shifts
  • Add poster images - Show preview before play
  • Consider autoplay policies - Many browsers block autoplay
  • Optimize file sizes - Use appropriate compression
  • Add captions/subtitles - Improve accessibility
  • Use preload wisely - Balance performance and bandwidth

Accessibility Considerations

  • Provide captions and subtitles
  • Include video descriptions
  • Use ARIA labels for custom controls
  • Ensure keyboard navigation works
  • Consider auto-pause when content is hidden
  • Provide transcripts for video content

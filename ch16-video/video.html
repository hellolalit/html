Chapter 16 - Video in HTML5


What is the Video Element?

The HTML5 video element is used to embed video content in web pages. It provides a standard way to include videos on your website without requiring third-party plugins like Flash. The video element supports various video formats and offers controls for playback, volume adjustment, fullscreen viewing, and more.


Basic Video Syntax

<video src="video-file.mp4" controls></video>

Video Attributes

The video element supports several attributes to control its behavior:

  • src - Specifies the URL of the video file
  • controls - Displays the default video controls (play/pause, volume, etc.)
  • width - Specifies the width of the video player
  • height - Specifies the height of the video player
  • autoplay - Starts playing the video automatically when the page loads
  • loop - Plays the video repeatedly
  • muted - Mutes the audio output
  • poster - Specifies an image to be shown while the video is downloading or until the user plays the video
  • preload - Specifies if and how the video should be loaded when the page loads
  • playsinline - Plays the video inline on iOS devices (instead of fullscreen)

Example with Controls and Poster

Here's an example of a video element with controls and a poster image:

<video
  src="movie.mp4"
  controls
  width="640"
  height="360"
  poster="movie-poster.jpg"
>
  Your browser does not support the video element.
</video>

Note: The text between the opening and closing video tags is displayed only if the browser doesn't support the video element.


Supported Video Formats

Different browsers support different video formats. The main formats used with the video element are:

Format File Extension MIME Type Browser Support
MP4 (H.264) .mp4 video/mp4 All modern browsers
WebM .webm video/webm Chrome, Firefox, Opera, Edge
Ogg .ogg video/ogg Firefox, Chrome, Opera

Multiple Source Formats

To ensure cross-browser compatibility, you can provide multiple video sources using the source element:

<video controls width="640" height="360" poster="movie-poster.jpg">
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.webm" type="video/webm">
  <source src="movie.ogg" type="video/ogg">
  Your browser does not support the video element.
</video>

The browser will use the first recognized format in the list.


Autoplay Attribute

The autoplay attribute starts playing the video automatically when the page loads:

<video src="background-video.mp4" autoplay></video>

Note: Many modern browsers block autoplay with sound to improve user experience. To autoplay video, you may need to also include the muted attribute:

<video src="background-video.mp4" autoplay muted></video>

Loop Attribute

The loop attribute makes the video play repeatedly:

<video src="background-video.mp4" autoplay muted loop></video>

Preload Attribute

The preload attribute specifies if and how the video should be loaded when the page loads:

<!-- No preloading (saves bandwidth) -->
<video src="large-video.mp4" preload="none" controls></video>

<!-- Preload metadata only (size, first frame, etc.) -->
<video src="movie.mp4" preload="metadata" controls></video>

<!-- Preload the entire video file -->
<video src="short-clip.mp4" preload="auto" controls></video>

Responsive Video

To make videos responsive (adapt to different screen sizes), you can use CSS:

<style>
  .responsive-video {
    width: 100%;
    height: auto;
    max-width: 100%;
  }
</style>

<video class="responsive-video" controls>
  <source src="movie.mp4" type="video/mp4">
</video>

For maintaining aspect ratio while resizing, you can use a container with padding-based technique:

<style>
  .video-container {
    position: relative;
    padding-bottom: 56.25%; /* 16:9 Aspect Ratio */
    height: 0;
    overflow: hidden;
  }

  .video-container video {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
  }
</style>

<div class="video-container">
  <video controls>
    <source src="movie.mp4" type="video/mp4">
  </video>
</div>

Background Video

Videos can be used as backgrounds for web pages:

<style>
  .video-background {
    position: fixed;
    right: 0;
    bottom: 0;
    min-width: 100%;
    min-height: 100%;
    width: auto;
    height: auto;
    z-index: -1;
  }
</style>

<video class="video-background" autoplay muted loop playsinline>
  <source src="background.mp4" type="video/mp4">
</video>

<div class="content">
  <h1>Content Over Video Background</h1>
</div>

JavaScript Video API

HTML5 provides a powerful JavaScript API for controlling video playback:

<script>
  // Get the video element
  const video = document.getElementById('myVideo');

  // Play the video
  function playVideo() {
    video.play();
  }

  // Pause the video
  function pauseVideo() {
    video.pause();
  }

  // Toggle fullscreen
  function toggleFullscreen() {
    if (video.requestFullscreen) {
      video.requestFullscreen();
    } else if (video.webkitRequestFullscreen) { // Safari
      video.webkitRequestFullscreen();
    } else if (video.msRequestFullscreen) { // IE11
      video.msRequestFullscreen();
    }
  }

  // Event listeners
  video.addEventListener('play', function() {
    console.log('Video started playing');
  });

  video.addEventListener('ended', function() {
    console.log('Video playback finished');
  });
</script>

Video Tracks

HTML5 video supports multiple tracks for subtitles, captions, descriptions, chapters, and metadata:

<video controls>
  <source src="movie.mp4" type="video/mp4">
  <track src="subtitles_en.vtt" kind="subtitles" srclang="en" label="English">
  <track src="subtitles_es.vtt" kind="subtitles" srclang="es" label="Spanish">
  <track src="descriptions.vtt" kind="descriptions" srclang="en" label="Descriptions">
</video>

The track element uses WebVTT (.vtt) files for subtitles and other text tracks.


Accessibility Considerations

When using video on your website, consider these accessibility best practices:

  • Always provide controls so users can control playback
  • Avoid autoplay with sound, as it can be disruptive
  • Provide captions or subtitles for deaf or hard-of-hearing users
  • Provide audio descriptions for blind or visually impaired users
  • Ensure video controls are keyboard accessible
  • Don't rely solely on video to convey important information

Video File Size and Performance

Video files can be large and impact page loading times. Consider these tips:

  • Use compressed formats with appropriate bitrates
  • Consider using the preload="none" or preload="metadata" attributes for large files
  • Use a content delivery network (CDN) for faster delivery
  • Consider adaptive streaming for different connection speeds
  • Optimize video dimensions for the intended display size
  • Use poster images to provide visual context before the video loads

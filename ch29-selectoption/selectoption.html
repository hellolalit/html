Chapter 29 - Select and Option in HTML5


What is a Select Dropdown?

The select element creates a dropdown list of options that users can choose from. It's commonly used in forms when you want users to select one or multiple options from a predefined list. The select element contains option elements that define the available choices.


Basic Select and Option Syntax

<select name="fruits" id="fruits">
  <option value="apple">Apple</option>
  <option value="banana">Banana</option>
  <option value="orange">Orange</option>
</select>

Select Attributes

The select element has several important attributes:

  • name - Specifies the name of the select element (for form submission)
  • id - Specifies a unique id for the select element
  • multiple - Allows the user to select multiple options
  • size - Specifies the number of visible options
  • required - Specifies that the user must select an option
  • disabled - Specifies that the select element should be disabled
  • autofocus - Specifies that the select element should automatically get focus when the page loads

Option Attributes

The option element has several important attributes:

  • value - Specifies the value to be sent to the server when the form is submitted
  • selected - Specifies that an option should be pre-selected when the page loads
  • disabled - Specifies that an option should be disabled

Option Groups

You can group related options using the optgroup element:

<select name="cars" id="cars">
  <optgroup label="European Cars">
    <option value="volvo">Volvo</option>
    <option value="mercedes">Mercedes</option>
  </optgroup>
  <optgroup label="American Cars">
    <option value="ford">Ford</option>
    <option value="chevrolet">Chevrolet</option>
  </optgroup>
</select>

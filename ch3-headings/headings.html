Chapter 3 - Headings in HTML

Understanding HTML Headings

HTML provides six levels of headings, from H1 to H6. H1 is the most important heading with the largest default font size, while H6 is the least important with the smallest default size. These headings help structure your content and improve both readability and SEO.

Heading Syntax

<h1>Main Title of the Page</h1>
<h2>Major Sections</h2>
<h3>Subsections</h3>
<h4>Sub-subsections</h4>
<h5>Minor headings</h5>
<h6>Least important headings</h6>

Best Practices for Using Headings

  • Use H1 for the main title: Each page should have exactly one H1 heading
  • Maintain hierarchy: Don't skip heading levels (e.g., don't go from H2 to H4)
  • Keep it meaningful: Use headings to describe the content that follows
  • Think about SEO: Search engines use headings to understand page structure
  • Consider accessibility: Screen readers use headings for navigation

Common Uses of Headings

  1. Page titles and subtitles
  2. Section headers in articles
  3. Blog post titles
  4. Sidebar widget titles
  5. Footer section headers

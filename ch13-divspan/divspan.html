Chapter 13 - Div and Span in HTML5


What are Div and Span Elements?

Div and span are container elements in HTML that are used to group and organize content. While they don't have any visual effect on their own, they are essential for applying styles, JavaScript functionality, and creating logical sections in your web pages.


The Div Element

The div element is a block-level container used to group larger sections of content or other HTML elements. It creates a new block in the document flow, meaning it starts on a new line and takes up the full width available.

<div>
  <h2>This is a heading inside a div</h2>
  <p>This is a paragraph inside the same div.</p>
</div>

The Span Element

The span element is an inline container used to group small pieces of content within a line of text. Unlike div, span doesn't create a new block and only takes up as much width as necessary.

<p>
  This is a paragraph with <span style="color: red;">some red text</span> in the middle.
</p>

Key Differences Between Div and Span

Feature Div Span
Display Type Block-level Inline
Line Break Creates new line No line break
Width Takes full width available Only as wide as its content
Usage Grouping larger sections Styling parts of text

Using Div for Layout

Divs are commonly used to create layout structures in web pages. With CSS, you can position, style, and arrange divs to create complex layouts.

<div class="container">
  <div class="header">
    <h1>Website Title</h1>
  </div>
  <div class="content">
    <p>Main content goes here.</p>
  </div>
  <div class="footer">
    <p>Footer content</p>
  </div>
</div>

Using Span for Inline Styling

Spans are perfect for applying styles to specific parts of text without disrupting the flow.

<p>
  This product costs <span class="price">$19.99</span> and is
  <span class="highlight">currently on sale</span>!
</p>

Div and Span with IDs and Classes

Both div and span elements are often used with ID and class attributes for CSS styling and JavaScript manipulation.

<!-- Using ID (unique identifier) -->
<div id="header">This is the header</div>

<!-- Using class (can be reused) -->
<div class="section">This is a section</div>
<div class="section">This is another section</div>

<!-- Span with class -->
<p>Some <span class="highlight">important</span> text.</p>

Practical Example

Here's a practical example showing both div and span in action:

Product Information

The Premium Headphones offer exceptional sound quality. They are available in blue, red, and green.

Price: $129.99

Free shipping on orders over $100

<div style="border: 1px solid #ddd; padding: 15px; border-radius: 5px;">
  <div style="background-color: #f0f0f0; padding: 10px;">
    <h3>Product Information</h3>
  </div>
  <div style="padding: 10px;">
    <p>
      The <span style="font-weight: bold;">Premium Headphones</span> offer exceptional sound quality.
      They are available in <span style="color: blue;">blue</span>, <span style="color: red;">red</span>,
      and <span style="color: green;">green</span>.
    </p>
    <p>
      Price: <span style="color: #e91e63; font-weight: bold;">$129.99</span>
    </p>
  </div>
  <div style="background-color: #f9f9f9; padding: 10px; border-top: 1px solid #ddd;">
    <p style="margin: 0; font-size: 14px;">Free shipping on orders over $100</p>
  </div>
</div>

Best Practices

  • Use semantic HTML5 elements (like header, footer, section, article) instead of div when appropriate
  • Don't overuse div elements (known as "div soup") - keep your HTML structure clean and meaningful
  • Use span only when you need to style a specific part of text
  • Always use classes and IDs with meaningful names
  • Separate structure (HTML) from presentation (CSS) by using external stylesheets

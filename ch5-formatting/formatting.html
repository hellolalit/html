Chapter 5 - Text Formatting in HTML

Understanding Text Formatting

HTML provides various tags for text formatting, allowing you to emphasize text, make it bold, italic, or apply other styles. Each formatting tag has its own semantic meaning and should be used appropriately.

Bold Text (B Tag vs STRONG Tag)

<b>Bold text</b> - Just visual formatting
<strong>Important text</strong> - Semantic importance

Example:

This text is bold but has no special meaning, while this text is important and has semantic value.

Italic Text (I Tag vs EM Tag)

<i>Italic text</i> - Visual styling
<em>Emphasized text</em> - Semantic emphasis

Example:

This text is italic for visual purposes, while this text is emphasized for meaning.

Other Text Formatting Tags

<mark>Highlighted text</mark>
<small>Smaller text</small>
<del>Deleted text</del>
<ins>Inserted text</ins>
<sub>Subscript</sub>
<sup>Superscript</sup>

Examples of Text Formatting

  • Highlighted text using mark tag
  • Smaller text using small tag
  • Deleted text using del tag
  • Inserted text using ins tag
  • H2O using sub tag
  • X2 using sup tag

Best Practices

  1. Use semantic tags: Choose strong/em over b/i when meaning is important
  2. Avoid overuse: Too much formatting can make text hard to read
  3. Consider accessibility: Semantic tags help screen readers understand content
  4. Combine with CSS: Use CSS for visual styling when possible
  5. Be consistent: Use the same formatting style throughout your site

Common Use Cases

  • strong tag: Warnings, important notes, keywords
  • em tag: Emphasis, stress, foreign words
  • mark tag: Highlighting search terms, key points
  • del tag and ins tag: Showing document changes
  • sub tag and sup tag: Mathematical and chemical formulas
